## 🔧 Development Usage

### Testing Scenarios:
1. **Search by blood type**: Test with all 8 blood types
2. **Camp registration**: Test with existing camps
3. **Emergency responses**: Test urgent request handling
4. **Donor management**: Test CRUD operations
5. **Geographic filtering**: Test by districts
6. **Date-based queries**: Test upcoming vs past camps

### Database Queries:
```sql
-- Find O- donors for emergency
SELECT * FROM donors WHERE blood_type = 'O-';

-- Most popular camps
SELECT c.name, COUNT(cr.registration_id) as registrations
FROM camps c LEFT JOIN camp_registrations cr ON c.camp_id = cr.camp_id
GROUP BY c.camp_id ORDER BY registrations DESC;

-- Recent emergency requests
SELECT * FROM emergency_requests 
WHERE requested_at >= '2025-07-30' 
ORDER BY requested_at DESC;
```

### Security Testing:
